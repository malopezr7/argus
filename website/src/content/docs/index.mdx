## The engine that ships is the engine that tests

Argus bundles each test file into a sealed IIFE, spawns the standalone `hermes` VM on it,
and reads a framed result line back. No Metro, no native build, no emulator — and no V8
pretending to be Hermes.

```ts
// sum.test.ts — plain TypeScript, running on the real Hermes VM
import { sum } from './sum';

describe('sum', () => {
  test('adds numbers', () => {
    expect(sum(2, 3)).toBe(5);
  });

  test('rejects a non-number', () => {
    expect(() => sum(2, 'three' as never)).toThrow(TypeError);
  });
});
```

```bash
npm install --save-dev @arguslab/argus
npx argus "src/**/*.test.ts"
```

One package, one binary. React is an optional peer — a pure-TypeScript suite runs without
it.

:::caution[Status]
Argus is at **`v0.1.1`** and installable from npm — one package, one binary. Pre-1.0: the
runner, matchers, mocks, source maps, synchronous component testing and the
[config file](/cli/configuration/) are built and verified, but the surface is still free to
change between minor versions. Snapshots, coverage and watch mode are not built — see the
[Roadmap](/reference/roadmap/) for what is landing and
[Limitations](/reference/limitations/) for what is out of scope on purpose.
:::
